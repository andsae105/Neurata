# Neurata!

-Neurata is a free Cognitive Function app that allows the user to access their cognitive function capabilities through our research approved tests that actually are 
indicative of some level of cognitive function.

---

## Features
- A simple UI Layout that makes it easy for the user to Navigate Around
- Tests that are categorized into 3 different sections: (Attnetion Span, Memory, and Proccessing Speed).
- Tests include... A Stroop Color Test, Corsi Block Tapping Test, as well as a Simple Reaction Time Test

---

## Materials to assemble this project

- X-Code
- SwiftUI
- and a cool Head!

---

## AI-Decleration

- AI was used in this project to be able to get us to understand basic SwiftUI. Not only that, but we found SwiftUI a bit more weirder compared to other languages we were used too, so some help was needed to learn its logic/style
- It was also used in terms of how to lay out the UI, how to be able to save test data locally and retrieve that data for our Library Page, and helping us understand a way where we could shift from one screen to another.
